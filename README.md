# بصيرة — Baseera
### التحقق من المحتوى الإسلامي وسياقه لتمكين المعرّفين بالإسلام
**تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي — المسار الرابع: "أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام"**

> **القاعدة الذهبية:**
> **"النموذج اللغوي لا يصدر الحكم الشرعي ولا يختلق المصدر. دور الذكاء الاصطناعي يكون في فهم المدخل، استخراج الآيات والأحاديث والمصطلحات، وتحليل السياق. أما الحكم بصحة الاستشهاد أو وجوده فيعتمد حصراً على مطابقة/استرجاع من المصادر المعتمدة. وعند عدم كفاية المرجع: الامتناع (لم يُعثر عليه في المراجع المفحوصة) أو الإحالة إلى مختص."**

---

## 1. المشكلة والهدف

يواجه المعرّفون بالإسلام، والمترجمون، وصنّاع المحتوى، والقراء تحديات حاسمة:
1. **خطر الهلوسة والتأكيد الخاطئ (False Confirmation):** نماذج الذكاء الاصطناعي العامة قد تؤكد صحة آية بلفظ مبدل، أو تنسب حديثاً للنبي ﷺ بلا إسناد، أو تختلق رقم آية.
2. **الترجمة الاختزالية للمصطلحات:** اختزال مصطلحات كبرى (مثل الشريعة إلى عقوبات جنائية فقط، أو التوحيد إلى مفهوم فلسفي مجرد، أو العبادة إلى طقوس معزولة).
3. **التخبط في المسائل الخلافية والفتاوى الشخصية:** إصدار أحكام قطعية في مسائل خلافية أو تقديم فتاوى في نوازل شخصية حساسة تتطلب الرجوع لأهل الاختصاص.

**بصيرة** تقدم طبقة برمجية مستقلة وصارمة تفصل بين استخراج الذكاء الاصطناعي وبين الحكم التوثيقي المستند للمصادر الرسمية.

## 2. معمارية المنظومة (Architecture)

```text
User Input (Text / URL / Image OCR / Audio STT)
                     ↓
              Baseera Unified API
                     ↓
           Input Normalization Layer
                     ↓
           AI Extraction Layer (Gemini)
                     ↓
       Canonical Source Retrieval & Matcher
    (Quran Database | Dorar Hadith | Jamhara Terms | Comparative Fiqh)
                     ↓
               Decision Engine
   (MATCHED | NEEDS_REVIEW | NOT_FOUND | REFER_TO_SPECIALIST)
                     ↓
       Word Diff & Citation Verification Layer
                     ↓
       Web App UI & Browser Extension Popup
```

## 3. سجل المصادر المعتمدة (Approved Source Registry)

لا تستخدم بصيرة أي مصادر دينية خارج الحزمة الرسمية المعتمدة:

| النطاق | المصدر المعتمد | الجهة المحققة | القيود والضوابط |
| :--- | :--- | :--- | :--- |
| **القرآن الكريم** | المصحف الشريف بالرسم العثماني | مجمع الملك فهد لطباعة المصحف الشريف | مطابقة تامة للنص والتشكيل وأرقام الآيات، لا يُقبل أي لفظ محرف أو مبدل. |
| **ترجمات القرآن** | الترجمات المعتمدة (صحيح إنترناشونال / حميد الله) | مجمع الملك فهد / quranpedia | بيان أن الترجمة اجتهاد بشري ونسبتها لمترجمها المعتمد. |
| **تفسير القرآن** | منصة تفسير الدرر وتفاسير القرون الثلاثة الأولى | الطبري، ابن كثير، البغوي | عدم اختلاق معانٍ مستحدثة خارج أقوال السلف المعتمدة. |
| **الحديث النبوي** | الموسوعة الحديثية | منصة الدرر السنية والمكتبة الشاملة | التحقق من صحة المتن والعزو والدرجة (صحيح، ضعيف، موضوع). عند عدم العثور يُصرح حصراً بـ: **"لم يُعثر عليه في المراجع المفحوصة"**. |
| **المصطلحات الإسلامية**| موسوعة الجمهرة لمفردات المحتوى الإسلامي | الحزمة المرجعية المعتمدة | منع الترجمة الاختزالية أو المشوهة (التوحيد، الشريعة، العبادة، الجهاد، الفطرة...). |
| **الفقه والمسائل** | الموسوعة الفقهية المقارنة والكتب المعتمدة للمذاهب الأربعة | الحنفي، المالكي، الشافعي، الحنبلي | عرض الخلاف السائغ دون ترجيح آلي، والامتناع التام عن الفتوى في النوازل الشخصية (المستوى د). |

> **المصادر المحظورة قطعيًا:** ويكيبيديا، محركات البحث المفتوحة كمصدر حكم، منصات التواصل والمنتديات، وأجوبة النماذج اللغوية غير المسندة.

## 4. مستويات اتخاذ القرار الشرعي (Levels A - D)

* **المستوى أ (Level A) — معلومة مستقرة:** إجابة موثقة مباشرة مع الدليل من القرآن أو السنة الصحيحة أو الإجماع.
* **المستوى ب (Level B) — شرح واستدلال:** شرح من المادة المعتمدة مع إظهار المرجع وتجنب القطع فيما يحتمل الخلاف.
* **المستوى ج (Level C) — مسائل خلافية:** عرض أقوال المذاهب الأربعة بتجرد دون ترجيح آلي بين الأئمة.
* **المستوى د (Level D) — فتوى أو حالة شخصية:** الامتناع الصارم، وتقديم توضيح عام، ثم إحالة فورية للجهات الإفتائية الرسمية أو المحاكم الشرعية.

## 5. المعيار المجمّد والتقييم التجريبي (Frozen Benchmark)

تم تجميد مجموعة اختبار مكونة من **150 حالة اختبار معيارية** تغطي:
* آيات صحيحة، آيات بكلمة مبدلة، أرقام آيات خاطئة.
* أحاديث صحيحة، أحاديث ضعيفة، أحاديث موضوعة، أحاديث منسوبة لمصدر خاطئ، نصوص مختلقة.
* مصطلحات سياقية ومصطلحات مترجمة ترجمة اختزالية مشوهة.
* مسائل فقهية مجمع عليها، مسائل خلافية بين المذاهب، وحالات شخصية/فتاوى.

## 6. إضافة المتصفح (Browser Extension — Reader Interface)

إضافة متصفح مبنية بمعيار Manifest V3 تتصل بنفس الـ Backend:
* تمكّن القارئ من تظليل أي كلمة أو حديث في أي صفحة ويب.
* عرض فوري لحالة التحقق (✓ مطابق، ⚠ يحتاج مراجعة، ↗ لم يعثر عليه).
* بيان المعنى المعتمد وسياقه من موسوعة الجمهرة.
* إظهار تنبيهات الاختزال والتشويه فورياً مع المصدر المعتمد.

ملفات الإضافة متوفرة في المجلد `/public/extension/`.

## 7. الربط البرمجي وخادم بروتوكول سياق النماذج (MCP Server)

تجاوزاً للاعتماد على الملفات المحلية الثابتة فقط، يوفّر مشروع بصيرة ربطاً حياً متكاملاً مع المصادر الرسمية:

### أ. الربط المباشر مع واجهة الدرر السنية (Live Dorar API):
* نقطة النهاية: `GET /api/dorar/search?q={hadith_text}`
* تبحث مباشرة في قاعدة بيانات **الموسوعة الحديثية بالدرر السنية** (`dorar.net/dorar_api.json`) التي تضم أكثر من **40,000 حديث مسند**.
* تسترجع: نص الحديث المعتمد، الراوي، المحدث، كتاب التخريج، الصفحة أو الرقم، وحكم المحدث المعتمد بدقة.

### ب. خادم بروتوكول سياق النماذج (Baseera MCP Server):
يدعم المشروع معيار **Model Context Protocol (MCP)** المفتوح، لتمكين أي وكيل ذكاء اصطناعي (Claude Desktop, Cursor, VS Code) من التحقق الشرعي عبر الأدوات التالية:
* `search_dorar_hadith`: استرجاع الأحاديث وحكمها مباشرة من الدرر السنية.
* `verify_quran_verse`: مطابقة الآيات الكريمة مع مصحف مجمع الملك فهد (6,236 آية).
* `lookup_jamhara_term`: فحص المصطلحات وكشف مؤشرات الاختزال والتشويه عبر موسوعة الجمهرة.
* `check_fiqh_ruling`: فحص المسائل الفقهية وضمان عدم إصدار فتاوى آلية شخصية (المستوى د).

تشغيل خادم MCP:
```bash
npm run mcp
```

إعداد خادم MCP في Claude Desktop أو Cursor (`claude_desktop_config.json`):
```json
{
  "mcpServers": {
    "baseera": {
      "command": "npx",
      "args": ["tsx", "mcp-server.ts"]
    }
  }
}
```

## 8. سياسة الخصوصية وأخلاقيات البيانات

* **حظر التنميط الديني:** لا تستنتج بصيرة أي بيانات شخصية أو توجهات فكرية أو مذهبية للمستخدم.
* **الحد الأدنى من البيانات:** معالجة لحظية آمنة دون تخزين نصوص المستخدمين الشخصية.
* **الأمان والعزل:** حماية مفاتيح البيئة وعدم إدراج أي أسرار في الكود المصدري.
